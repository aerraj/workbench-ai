# Workbench

Your personal AI workspace.

**[Open Workbench →](https://workbench-ai.aerraj.workers.dev/)**

## Features

- Sign in with Google or a username and password.
- Chat with OpenAI, Anthropic, Gemini, and OpenRouter using your own API keys.
- Upload and analyze documents, spreadsheets, presentations, and images.
- Create Word documents, PowerPoint decks, images, code, and charts.
- Preview, edit, and download generated artifacts.
- Save conversations, files, and API keys with server-side encryption.
- Streaming replies, chat search, and light/dark themes.
